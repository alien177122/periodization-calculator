# Selfstudy standards — авторские документы самоучителя

Здесь лежат авторские документы самоучителя «Журнал Сплит». Они НЕ показываются в превью приложения и НЕ хранятся в `selfstudy/content/`.

## Файлы

- `THROUGHLINE.md` — красная нить самоучителя: шесть опор стези, голос объяснителя, правила честности. Обязателен к прочтению перед написанием любой статьи.
- `TEMPLATE.md` — универсальный шаблон статьи: уровни «Просто/Подробно/Вглубь», таблицы, Mermaid, «Что запомнить», «Куда это ведёт».

## Конвенция

1. **Источник авторских документов** — этот каталог (`docs/selfstudy-standards/`). Рабочая копия ведётся в корпусе `~/Desktop/kb-structured-*/articles/` вместе со статьями; синхронизируй оба места при правках.
2. **`selfstudy/content/`** — только читательский контент: статьи `A-…`–`O-…` и читательская версия `learning-path.md` (без секции «№0 для авторов» и без упоминаний TEMPLATE/THROUGHLINE). Копии THROUGHLINE.md/TEMPLATE.md туда класть запрещено.
3. **`learning-path.md`** существует в двух версиях: авторская (в корпусе, с правилами сборки и №0) и читательская (в `selfstudy/content/`, только маршрут и статьи). Не пересинхронизируй одну в другую целиком.
4. Превью приложения читает `selfstudy/content/*.md` через `import.meta.glob` — новый файл статьи появляется в превью автоматически.
