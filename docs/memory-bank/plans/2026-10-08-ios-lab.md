# План: лаборатория iPhone

**Дата:** 2026-10-08

## Цель

Симулятор iPhone в Xcode открывает dev-ссылку `http://127.0.0.1:5173/`, не туннель. Туннель остаётся для настоящего телефона вне дома.

## Критерий готовности

- [x] Лаборатория лежит в `Desktop/React/ios/`
- [x] Зафиксирована dev-ссылка `http://127.0.0.1:5173/`, туннель в симулятор не подставляем
- [x] Runtime iOS 26.3 установлен, симулятор iPhone 17 открыл `http://127.0.0.1:5173/` (экран входа журнала)

## Решение

Симулятор — Xcode. Открытого симулятора iOS, который сам запускает iPhone, нет. Dev-сервер журнала уже слушает порт 5173. Настоящий iPhone ставим позже, когда он подключён кабелем.

## Шаги

1. Скачать runtime iOS (`xcodebuild -downloadPlatform iOS`).
2. Загрузить симулятор iPhone 17 и открыть dev-ссылку в Safari.
3. На подключённый iPhone сборку ставить отдельным шагом.
