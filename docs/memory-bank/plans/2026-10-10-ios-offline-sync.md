# Офлайн-синхронизация журнала

## Цель

После одного успешного входа журнал работает без сети: правки остаются на устройстве и уходят на сервер, когда связь возвращается. Сверху приложения виден короткий индикатор связи.

Критерий готовности: при обрыве сети локальная правка не откатывается и попадает в outbox этого пользователя; после ответа `/api/health` тот же снимок уходит PUT и outbox очищается; чужой outbox не применяется; `tests/offline-outbox.test.ts` и `npm run typecheck` проходят. Пересборка iOS — только если она дешёвая и на диске больше 8 ГиБ.

## Пункты

1. Чистые хелперы outbox и подписей в `packages/shared`, экспорт в `package.json`.
2. `saveUser`: сетевой обрыв → `{ok:true, pending:true}` и запись outbox; HTTP 4xx/5xx → `{ok:false}` без outbox; успех очищает outbox, если за время запроса не появился более новый снимок.
3. `optimisticSave` не откатывает ответ с `pending`.
4. Загрузка сессии: outbox этого пользователя важнее копии сервера; при недоступном API не разлогинивать, если есть локальный снимок.
5. Зонд `/health` примерно раз в 15 с и по событию `online`; при успехе и outbox — PUT, на время запроса статус syncing.
6. Индикатор в каждой ветке `AppShell` и стили в `app-layout.css`.
7. Убрать `server.url` туннеля из capacitor config. Xcode не запускать, если сборка не дешёвая.
8. Обновить `Desktop/React/ios/README.md` и PDF, если pandoc жив.
9. Прогнать новый тест и typecheck.

## Проверка цели

Свободное место уже больше 8 ГиБ. Полная сборка Capacitor/Xcode не считается дешёвой: уже установленное приложение симулятора продолжит открывать старый URL до следующей сборки. Веб-клиент, в том числе симулятор по `127.0.0.1:5173`, получает офлайн-слой без пересборки.
