# Упрощение конструктора сплита · план от 2026-11-15

Статус: видение владельца. Код не менялся.

## 1. Видение

Сейчас конструктор — это инструмент персонального тренера: профили, названия сплитов,
база силовых, сохранение/дублирование, выбор сплита из списка. Для обычного атлета это
перегруз: он хочет просто «стандартную программу» или «свой набор упражнений».

**Новый конструктор — два входа:**

1. **«Базовая тренировка»** — read-only стандартная программа (12 упражнений, 2 дня,
   волна 8 недель). Открыл → посмотрел → «Начать». Никакого редактирования.
2. **«Своя тренировка»** — выбор упражнений (4–8 на день), дней в неделю, весов.
   Сохраняется как личный сплит.

Профили, названия сплитов, база силовых, дублирование — **не удаляются**, но уходят
за «Расширенный режим» (для тренеров и продвинутых). По умолчанию показывается
упрощённый вид.

## 2. Что убирается из основного вида

- Поле «Название сплита» + подсказка (переносится в расширенный режим).
- Блок «Сплиты профиля» с picker/редактирование/удаление (расширенный режим).
- Блок «Профили» с переименованием (расширенный режим).
- «Повторить» / «Сохранить» / «+ Новый сплит» (расширенный режим).
- «База силовых профиля» (расширенный режим или отдельный экран настроек).

## 3. Что остаётся в основном вида

- Переключатель «Базовая / Своя».
- Для «Своей»: выбор упражнений на день (уже есть `customExercisesByDay`), дни в неделю (2/3/4), схемы подходов (5×4).
- Кнопка «Начать тренировку».
- Связки упражнений (S3) — в «Своей».

## 4. Принцип

Основной вид = 2 кнопки + выбор упражнений + старт. Расширенный режим — по кнопке
«Расширенный» в шапке, открывает текущий конструктор целиком (профили, сплиты,
база весов). Ничего не удаляется из данных и логики — только скрывается за переключателем.

## 5. Этапы

- **SC1 (S)** — ✅ реализовано: упрощённый вид с двумя входами («Базовая тренировка» /
  «Своя тренировка») и переключателем «Расширенный режим». Профили/сплиты/база весов
  скрыты по умолчанию. Проверено: рендер OK, typecheck/lint чистые.
- **SC2 (M)** — перенос профилей/сплитов/базы весов за переключатель.
- **SC3 (S)** — онбординг: «введите 12 упражнений для базовой программы» как
  отдельный шаг (опционально, если профиль пуст).
- **SC4** — проверка на 393px, typecheck/lint.

Оценка: SC1 S, SC2 M, SC3 S. Коммиты — только по команде.
