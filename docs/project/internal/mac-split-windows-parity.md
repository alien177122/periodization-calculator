## Основной сценарий (Venus)

1. Выбрать профиль и при необходимости открыть «База силовых профиля» (веса по умолчанию для **новых** расчётов).
2. В toolbar выбрать или создать сплит (шаблон программы в профиле).
3. В **истории расчётов** нажать **«Открыть»** на нужном расчёте — в state подставляются `draft` ← `calculation.split` и веса ← `calculation.exercises`.
4. Секции **02–04** доступны только при выбранном расчёте (или первом расчёте сплита / черновике нового).
5. Добавить/убрать упражнения, поправить веса → **«Пересчитать и обновить»** — тот же `calculation.id`, обновлённые `split` + `exercises` (правка **на месте**, не абстрактный сплит без якоря).

Если есть расчёты, но ни один не выбран (`activeSplitCalculationId`), показывается подсказка: выберите расчёт в истории.

## Изменения в коде (этот проход)

- `src/screens/SplitConstructorTab.tsx` — гибридная вёрстка 01–04, gating секций 02–04 по якорю расчёта.
- `src/components/split/SplitProfilePanel.tsx` — профиль + база силовых (вынесено из `SplitHub`).
- `src/components/split/SplitToolbar.tsx` — восстановлен chrome сплитов (старый Mac).
- `packages/shared/src/hooks/useSplitConstructor.ts` — `previewSplit` и `calculateSplit` работают от **draft** при правке выбранного расчёта.

`SplitHub.tsx` больше не используется вкладкой Split (оставлен в репо на случай отката).

## Не переносилось с Windows

- Профиль через поля toolbar Windows (имя + select) — на Mac остаётся список профилей.
- Отдельный модальный «Редактор сплита» — убран; правка только через выбранный расчёт + секции 02–03.

## UI (узкий экран)

- **Дней в неделю:** `.split-toolbar .split-segment` — одна строка, три равные колонки (`repeat(3, minmax(0, 1fr))`), без переноса 2+1; на ≤430px container — `type-12` и компактный padding. Проверять ~360–400px.
