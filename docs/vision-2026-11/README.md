## Дайджест Europe PMC (`research/europepmc-digest/`)

Машиночитаемый сбор мета-анализов и ключевых работ из Europe PMC REST API (без ключей), 2015–2026, 39 запросов. 10 тем: объём силовой, частота, периодизация, RIR/близость к отказу, автокоррекция/RPE, VBT, grip-strength↔смертность, VO2max↔смертность, сон/тестостерон/метаболизм, стероиды и сердце.

- `digest.md` — выжимки «что нашли»; в выжимку попадает только то, что реально написано в abstract (без домыслов; отсутствие abstract указано явно).
- `key-numbers.md` — точные цифры с цитатой и DOI; вход для статей самоучителя и честных заметок в UI.
- `meta-analysis-digest.jsonl` — запись = один запрос (topic, query, hitCount, results[]); `raw/` — сырые ответы API; `scripts/` — фетчеры и билдер (`fetch_europepmc.py`, `supplement*.py`, `build_digest_md.py`).
- `_dedup_*.json` / `_shortlist_*.json` — дедуп и шортлист по каждой из 10 тем.

## Данные мышечных карт (`docs/muscle-maps/muscle-maps.json`)

v0.2.0 (2026-11-08): 17 записей, покрывают все 16 упражнений каталога (становая разнесена на классику/трэп-гриф), шкала **stimulus-intensity-0-100** (степень стимула мышцы в упражнении; доли не эксклюзивны и не обязаны суммироваться в 100). У каждой карты — `sources` из кодов: `repo:muscle-contrib` (числа из расчёта объёма, нормализованы на целевую = 100), `estimate` (экспертная оценка по механике), `conspect:yeti:…` (ссылка на конспект), `anthropometry:…` (параметризация от телосложения; `anthropometrySensitive` — сейчас только жим ногами с высокой постановкой). Связь: карточка хаба №3 «Мышечные карты нагрузки»; вариант B калькулятора уже подгружает этот JSON в карты стимула (с бейджем источника у каждой, fallback на доли объёма дня из `MUSCLE_CONTRIB`).
