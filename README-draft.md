# Журнал Сплит

Я написал приложение силовой периодизации: журнал тренировок, конструктор сплита, калькулятор нагрузок и раздел «Теория». Оно решает главную боль зала — отсутствие системы: люди ходят годами и стоят на месте, потому что не знают, от каких процентов считать и когда повышать вес.

## Как это работает

- Пользователь делает **один тестовый подход** (5–8 повторений) — единственный обязательный ввод.
- Из него рассчитывается **1ПМ** (Эпли / Бжицки) — без проходок на максимум.
- Сразу на выходе — **8-недельная программа волновой периодизации**: лёгкие и тяжёлые недели идут волной, тестовые недели пересчитывают 1ПМ и сдвигают волну целиком.
- Рабочие веса округляются **до реальных блинов**, разминка и схемы подходов×повторений строятся автоматически.
- **Журнал** замыкает контур: записанные сессии дают e1RM, тоннаж и дельту за 4 недели — обратная связь без ручного анализа.
- **Конструктор сплита** (2/3/4 дня) считает объём по мышцам и прогнозирует тоннаж.

## Стек и почему именно он

- **React 19 + TypeScript + Vite 7** — быстрый дев-цикл и типобезопасность: ошибка в формуле = ошибка в плане тренировок.
- **npm workspaces + `packages/shared`** — вся расчётная логика в одном общем пакете: её переиспользуют веб и мобильные обёртки, и она покрыта тестами независимо от UI.
- **Node.js + Express 5 + SQLite** — простой самодостаточный бэкенд без внешних СУБД: один процесс, один файл базы — легко деплоить и бэкапить.
- **JWT + rate limiting** — stateless-авторизация и защита API от перебора паролей.
- **PWA** — установка на домашний экран iPhone как полноценное приложение, без App Store.
- **Capacitor** — нативная iOS-обёртка поверх того же веб-кода — путь в App Store без переписывания.
- **Docker Compose + Vercel** — деплой: фронт — статика на Vercel, API — контейнер на своём хосте.
- **ESLint + Prettier + husky + lint-staged** — автоматическое качество кода на каждом коммите.

## Качество
